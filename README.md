# ♊ Gemini Parallel Plugin

**让 Gemini 具备"平行推演 + 同屏搜索 + 看完即焚 + 一键导出" 能力的交互增强扩展。**

> 一款 Chrome 浏览器扩展，给 [gemini.google.com](https://gemini.google.com) 加一层"工作流护城河"——主线归主线、支线归支线；看完可物理销毁；产出会被自动沉淀。

---

## ✨ 核心特性

| 维度 | 能力 |
|------|------|
| **💡 平行推演** | 划选任意文字 → 侧边栏开新对话窗口，**不污染**主线上下文 |
| **🔍 同屏搜索** | 划词后直接调 Google，搜索结果在侧边栏内打开（**跨域**渲染） |
| **🕐 时间轴导航** | 右侧悬浮时间轴节点，点击直达任意一轮对话；主屏与侧栏**各自独立** |
| **🗑️ 看完即焚** | 物理级抹除云端 + 客户端历史记录，**全程零闪烁**（CSS 隐藏 + Observer 边听边点） |
| **📦 一键导出** | 单条 AI 回答 `📸 存为长图` / 整段对话 `📦 导出项目上下文 / Markdown / JSON` |
| **🎯 零摩擦对焦** | DOM 节点注入技术，划选后指令自动落到第二行 + 光标就位，无需鼠标二次点击 |
| **🪄 合并回主线** | 侧栏推演满意后，一键 `✨ 合并` 把内容带回主对话 |
| **🌒 深色模式** | 自动跟随 Gemini 主题（light / dark），胶囊、菜单、iframe 全部适配 |

## 🎬 快速开始

### 1. 开发者模式安装

1. 下载并解压本仓库。
2. Chrome 地址栏打开 `chrome://extensions/`。
3. 开启右上角 **「开发者模式」**。
4. 点击 **「加载已解压的扩展程序」**，选择本项目根目录。
5. 打开 [https://gemini.google.com](https://gemini.google.com)，扩展即生效。

> 每次代码改动后，需要在 `chrome://extensions/` 点 **「重新加载」** 才会生效。

### 2. 核心链路验证

按下面顺序跑一遍，确认 6 个核心动作都通：

| # | 动作 | 预期 |
|---|------|------|
| 1 | 划选任意文字 | 浮窗弹出 `💡 平行对话` / `🔍 Google 搜索` |
| 2 | 点击 `💡 平行对话` | 右侧滑出侧栏，光标自动落到引导语**第二行**闪烁 |
| 3 | 侧栏内输入对话 | 节点出现在**侧栏**自己的时间轴上（不与主屏混合） |
| 4 | 主屏点头部 `🗑️ 遗忘` | 插件二次确认 → ✅ 已销毁 → 侧栏关闭，**全程无 Gemini confirm 闪烁** |
| 5 | 主屏时间轴点 `📦 导出对话` | 弹出菜单：`项目上下文` / `完整 Markdown` / `JSON 数据` 三选一 |
| 6 | AI 回答后点 `📸 存为长图` | 浏览器下载 PNG，完整含长代码块、公式、折叠文本 |

## 🧭 使用指南

### A. 划选浮窗（核心入口）

页面任意位置**划选 2 字以上** → 出现 2 个动作胶囊：

- **💡 平行对话**：把上下文注入侧栏，作为"支线"继续推演
- **🔍 Google 搜索**：在侧栏内开 Google 搜索结果页（**跨域**渲染完整网页）

### B. 时间轴导航（视觉地图）

主屏和侧栏各有一条**独立**时间轴（id 命名空间完全隔离）：

- 节点位置 = 该轮对话在页面里的累积高度百分比
- 点击节点 → 滚动到对应 query
- `↑` / `↓` → 跳到首条 / 最新一条对话
- 节点 hover → tooltip 摘要 + 可删除

> **ADR-3 决策**：每个会话/窗口独立时间轴 —— 节点归属清晰，不串台。

### C. 时间轴底部胶囊组（主屏专属）

主屏时间轴底部垂直挂着 **3 枚胶囊**（FAB），自上而下：

| 顺序 | 胶囊 | 颜色 | 作用 |
|------|------|------|------|
| 1 | 🗑️ 销毁窗口 | 红 | **物理**删除当前主屏会话（云端 + 本地） |
| 2 | 📦 导出对话 | 绿 | 三种格式导出整段对话 |
| 3 | 🔍 平行搜索 | 蓝 | 主动开搜索模式（无需先划选） |

> **ADR-2 决策**：FAB 视觉对齐时间轴（`right: 30px`），但 `position: fixed` 独立浮窗 —— 不嵌在 30px 宽容器内，**彻底避开** 100px 胶囊对节点和 ↑↓ 按钮的横向覆盖。

### D. 导出对话（三种格式）

点击 `📦 导出对话` 弹出菜单：

- **项目上下文 (.md)**：自带启动提示 + 问题列表 + 原始对话 —— **直接喂给新会话**就能继续
- **完整 Markdown (.md)**：每轮问答分段、含时间戳、含原始链接
- **JSON 数据**：结构化 `{ title, source, exportedAt, conversation: [...] }`

文件名格式：`gemini-conversation-2026-06-07T15-08-57.md`，按本地时间打戳。

### E. 单条回答存为长图

每条 AI 回答下方出现 **`📸 存为长图`** 按钮：

- 离屏虚拟画板渲染（折叠文本、滚动长代码块**完全铺开**）
- 解决 P3 色彩 / CORS 跨域 / 重影问题
- 浏览器直接下载 `Gemini_推演长图_<timestamp>.png`

### F. 销毁/遗忘（看完即焚）

- **侧栏** 点头部 `🗑️ 遗忘` → 插件二次确认 → ✅ 已销毁 → 侧栏关闭
- **主屏** 点时间轴 `🗑️ 销毁窗口` → 插件二次确认 → ✅ 已销毁 → SPA 回首页

> **ADR-1 决策**：用 CSS `display: none` + `MutationObserver` 边听边点 Gemini 自带的 confirm 弹窗 —— 弹窗插入 DOM 的同一帧就被隐藏，**视觉上看不到闪烁**。

### G. 合并回主线

侧栏推演满意后 → 点头部 `✨ 合并` → 自动把内容贴回主屏输入框 + 触发发送逻辑（**不会自动发送**，交还用户控制权）。

### 关键模块（`content.js`）

| 模块 | 职责 |
|------|------|
| `showFloatingMenu` | 划选浮窗，2 个动作胶囊 |
| `openSidebar` / `closeSidebar` | 侧栏 iframe 生命周期（含 interval 清理防内存泄漏） |
| `renderTimeline` | 主屏时间轴节点渲染（2s 轮询） |
| `renderSidebarTimelineInIframe` | 侧栏时间轴节点渲染（id 前缀 `gemini-sidebar-timeline-*` 隔离） |
| `executeForgetBranch` | 侧栏分支销毁（CSS 隐藏 + Observer 边听边点 = 零闪烁） |
| `destroyMainConversation` | 主屏销毁（走主屏 `document`） |
| `performDestroyOnDocument` | 通用销毁引擎（菜单打开 → Delete → confirm 物理点击） |
| `exportGeminiConversation` | 整段对话导出（context / full / json 三模式） |
| `injectCSSIntoIframe` | 侧栏 CSS 注入（`declarativeNetRequest` 已剥 X-Frame-Options） |

### 关键 ADR

| # | 决策 | 原因 |
|---|------|------|
| 1 | 销毁闪烁消失 = CSS 隐藏 + Observer 边听边点 | CSS 同步应用，弹窗插入 DOM 同一帧就 `display: none` |
| 2 | 销毁/导出/搜索 3 枚 FAB = `position: fixed` 独立浮窗 + `right: 30px` 视觉对齐 | 30px 容器 + 100px 胶囊 = 100% 横向覆盖节点 + ↑↓ 按钮 + 阴影模糊 |
| 3 | 主屏 + 侧栏各自独立时间轴 | 节点归属会话所在的窗口，不串台 |
| 4 | 侧栏时间轴无 FAB | 避免视觉杂乱；侧栏标题栏的 🗑️ 遗忘继续负责销毁 |

## 🛠️ 技术栈

- **纯 JavaScript**（无构建系统，无 TypeScript）
- **Chrome Extension Manifest V3**
- **declarativeNetRequest**（`rules.json`）剥 iframe X-Frame-Options / CSP
- **html-to-image + 离屏虚拟画板**（长图导出引擎）
- **CSS 变量**（`--gemini-island-bg` / `--gemini-border` / `--gemini-shadow`）适配深色模式

### 选择器兼容性

Gemini 改版后新旧选择器**双写**：

```js
try { getByTestId } catch { getByTestIdWithDash }
// data-testid  （新版，无连字符）
// data-test-id（旧版，有连字符）
```
